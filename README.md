# 利用Cloudflare反代境外AI服务实现国内访问
想必你也曾为此困扰：“想使用国外的AI服务，却苦于没有科学上网的方法。”而今天这个**免费**服务，或许能帮你解决这一难题。
## 食用方法
### Google Gemini

- 在API URL填写`https://gemini.aiapi.pages.dev`
	```TEXT
	https://gemini.aiapi.pages.dev
	```
- 在API KEY填写你自己在 [Google AI Studio](https://aistudio.google.com/api-keys) 申请的KEY
	- 注：访问 Google AI Studio 需要科学上网，申请 KEY 需要 Google 账号。
#### OpenAI

- 在API URL填写`https://openai.aiapi.pages.dev`
	```TEXT
	https://openai.aiapi.pages.dev
	```
- 在API KEY填写你自己在 [OpenAI](https://openai.com) 申请的KEY
	- 注：访问 OpenAI 需要科学上网

#### 示列

- 以 Cherry Studio 使用 Google Gemini 为例
- ![操作步骤](https://i-blog.csdnimg.cn/direct/bc98ffbbe8854e32a71f9fdcc416be76.png)
1. 点击侧边栏下面的设置图标
2. 点击 `Gemini`
3. 将API 地址设为`https://gemini.aiapi.pages.dev`
4. 在API 密钥填写你自己提前在[Google AI Studio](https://aistudio.google.com/api-keys) 申请的密钥
